# Site vitrine – Fanny Gerszkourez, ostéopathe à Bayeux

Site statique [Astro](https://docs.astro.build). Prérequis : Node.js ≥ 22.

```sh
npm install
npm run dev      # http://localhost:4321 (rechargement automatique)
npm run build    # vérifie et génère dist/
npm run preview  # sert dist/ comme en production
```

- Modifier les infos du cabinet : `src/data/site.ts`
- Modifier un texte de soin : `src/content/soins/`
- Avancement et prochaines étapes : `docs/PLAN.md`
- Instructions pour les assistants IA : `AGENTS.md`
